## Third-Party vs. Official

**CRITICAL distinction:**
- ✅ **Official:** Built by Anthropic, validated in docs
- ⚠️ **Third-Party:** Community-built, use at own discretion
- ✅ **Validated:** Tested by power users, stable
- ❌ **Unverified:** Not tested, may have issues
